# MIGLANI — дом и подворье

Приложение семьи Мигланов для дома и подворья: дела на каждый день, счета и учёт денег, машина, покупки и цены в магазинах,
рационы коз, лошадей, кур и коровы, запасы кормов, журнал надоев и яиц, помощник Claude, план развития хозяйства, отчёт на почту.
Фото вместо записи от руки: весы, кувшин, счёт, чек заправки, чек из магазина (фото или PDF из Mans Rimi), ценники, склад.

- Сайт и установка на телефон: https://cesarcomando.github.io/podvorye/ (в браузере телефона: меню → «Установить приложение» / «Добавить на главный экран»)
- Работает без интернета: всё сохраняется в телефоне и отправляется в базу, когда появится связь.
- База и вход: Supabase-проект `podvorye` (`zluiwncfigibykwyxhcj`, Стокгольм).

## Разделы

| Вкладка | Что там |
|---|---|
| Дела | ежедневник: Просрочено → Сегодня → Завтра → На неделе → Без срока, быстрое добавление строкой («купить комбикорм завтра 10:00»), разделы Хозяйство / Дом / Личное, повторы, напоминания, календарь месяца, заметка дня, «В Google Календарь» и .ics, «Поделиться» → «Подворье» |
| Дом | Счета (напоминания, реквизиты, «Оплачено» → Учёт, по фото); Учёт — общий (доходы/расходы по разделам, категории списком: яйца, молоко, овощи, петухи…, правка ✎ любой записи, CSV) и 🔒 «Мой бюджет» (личный, см. ниже); Машина (заправки — пробег по желанию, расход на 100 км, техосмотр/OCTA/ТО); Покупки («Домой», «Деду», «В магазине», где дешевле, маршрут); Корзина (что покупаем регулярно, сколько в месяц, где дешевле — по чекам); Магазины (адреса, цены, кнопка «🏷️ Буклет акций»: Maxima, Rimi, Lidl, Mego, top! — visasakcijas.lv, ABrands — abrands.lv); Тепло |
| Рацион + Советы | нормы, «Составить рацион», «Подобрать дешевле»; советы, чего нельзя, экономика, план развития |
| Запасы | Корма: «Склад» (остатки, цены, «В дела»), «Где выгоднее» (мешки разных магазинов по цене за 1 кг, «Купила корм» → Учёт и склад, подсказка, что было дешевле), «Дневник корма» (сколько дала, яйца, куры, условия, отзыв ★1–5; итог: яиц на курицу в день и корм на одно яйцо) |
| Журнал | надои, яйца, вес, график и сравнение до/после смены рациона |
| Хозяйство | животные, свои корма, отчёт и утреннее письмо, участники и приглашения, резервная копия |

Все общие данные — один документ `farms.data` (`S` в `src/app.js`): `animals`, `feeds`, `log`, `tasks`, `money`, `days`, `settings`,
`bills`, `cars`, `fuel`, `shopItems`, `shopPrices` (у кормов ещё `kg` — вес мешка и `feed` — какой корм рациона), `stores`, `requests`, чеки — `receipts`, дневник корма — `feedLog`.
Дела и учёт сливаются между телефонами по `id` и `updatedAt`; удаление — пометка `deleted`.

**🔒 Мой бюджет** — личный раздел в «Учёте»: доходы каждый месяц, кредиты (остаток, платёж, ставка, сколько месяцев осталось, какой гасить первым), подписки, траты и разовые доходы по месяцам, итог «Остаётся».
Хранится не в `farms.data`, а в отдельной таблице `private_data` (одна строка на человека); правило в базе — читать и менять может только сам владелец, другие участники хозяйства не видят. Личные цифры в код не вписываются: репозиторий открытый.

**Чеки из магазина:** «📷 → Чек магазина», до 15 файлов за раз, по одному чеку на файл (один запрос к помощнику на чек). PDF превращается в картинки прямо в телефоне (`src/pdf.js`, pdf.js грузится с jsDelivr только при выборе PDF), длинный чек режется на куски. После проверки: сумма → Учёт (Дом, Продукты), цены → Магазины, товары → Корзина; повторный чек распознаётся и не записывается дважды.

**Кнопка «Назад» телефона** — шаг назад: закрывает открытое окно, возвращает прошлый раздел, фильтр, день или месяц; выход — только с первого экрана.

**Подсказка «?»** — пошаговая инструкция по разделам; при новых разделах номер версии (`TOUR_V` в `src/tour.js`) увеличивается, и подсказка предлагается ещё раз.

Локально без входа: `npm run dev`, затем открыть `http://localhost:5173/#demo` (демо-данные, только в режиме разработки).

## Как устроено

| Часть | Где |
|---|---|
| Приложение (HTML/JS, PWA) | `index.html`, `src/app.js`, `src/style.css` |
| Связь с базой, вход, синхронизация, вызов помощника | `src/backend.js` |
| Таблицы и права доступа (RLS) | `supabase/migrations/001_init.sql` |
| Личный бюджет (`private_data`, видит только владелец) | `supabase/migrations/004_private_budget.sql` |
| Чек в PDF → картинки | `src/pdf.js` |
| Пошаговая подсказка | `src/tour.js` |
| Расписание отчёта (понедельник 05:00 UTC) | `supabase/migrations/002_weekly_cron.sql` |
| Утреннее письмо с делами (каждый день 04:30 UTC) | `supabase/migrations/003_daily_cron.sql`, режим `?mode=daily` в `weekly-report` |
| Помощник Claude (ключ только на сервере) | `supabase/functions/ask-farm` |
| Еженедельный отчёт (Resend) | `supabase/functions/weekly-report` |

## Секреты (Supabase → Edge Functions → Secrets)

| Секрет | Зачем |
|---|---|
| `ANTHROPIC_API_KEY` | ключ Claude из console.anthropic.com |
| `ANTHROPIC_MODEL` | необязательно; по умолчанию `claude-opus-5-5`, дешевле — `claude-sonnet-5-5` или `claude-haiku-5-5` |
| `AI_DAILY_LIMIT` | необязательно; запросов к помощнику в день на человека, по умолчанию 40 |
| `CRON_SECRET` | уже задан; тот же лежит в Vault как `cron_secret` |
| `RESEND_API_KEY`, `REPORT_FROM` | для писем: ключ resend.com и отправитель с подтверждённым в Resend доменом |

Помощник работает только в хозяйствах, где в таблице `farms` включено `ai_enabled` (включается вручную, чтобы ключом не пользовались посторонние).
