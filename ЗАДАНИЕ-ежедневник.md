# Задание: ежедневник для Насти внутри «Рационов подворья»

Делать после текущей работы, по шагам. После каждого шага — коротко: что сделано и что проверить на телефоне.
Ничего из существующего (рационы, запасы, советы, журнал, хозяйство, помощник, отчёт) не ломать и не убирать.

## Как встроить (под текущее устройство приложения)
- Все новые данные — в тот же документ `S` (`farms.data`): `S.tasks[]`, `S.money[]`, `S.days{}` (заметка дня).
  Дописать их в `blank()` и `normalize()`. Так они сами сохраняются в телефоне, работают без интернета
  и синхронизируются у всех участников хозяйства.
- `mergeData()` сейчас сливает только `log`. Для `tasks` и `money` — слияние по `id`: у каждой записи `updatedAt`,
  побеждает более свежая; удаление — пометка `deleted: true` (а не вырезание из массива), иначе удалённое вернётся с другого телефона.
- Новые вкладки в `nav.tabs` и в карту видов в `render()`; в `style.css` сетка вкладок `repeat(5,1fr)` → под новое число.
  Ежедневник должен открываться и когда животных ещё нет (сейчас `render()` в этом случае показывает только пустой экран).

## 1. Вкладка «Дела» (первая слева, открывается по умолчанию)
Дело: название, раздел (Хозяйство / Дом / Ферма / Личное), срок (дата, время — по желанию), приоритет (обычный / важно),
повтор (нет / каждый день / неделю / месяц / год), напоминание (нет / в момент срока / за 1 час / за 1 день), заметка, отметка «сделано».
- Экран «Сегодня»: Просрочено (красным) → Сегодня → Завтра → На неделе → Без срока. Фильтр по разделу чипами.
- Строка быстрого добавления сверху: «купить комбикорм завтра 10:00» — дату и время понять из текста (сегодня/завтра/послезавтра, дни недели, «12.11», «10:00»).
- Отметила «сделано» у повторяющегося — создаётся следующее по повтору.
- Листание по дням (‹ сегодня ›) и маленький календарь месяца с точками на днях, где есть дела; «Заметка дня».
- Связь с хозяйством: из «Пора докупать» на складе — кнопка «В дела» (создаёт дело «Купить …» в разделе Хозяйство).

## 2. Вкладка «Учёт»
Запись: дата, доход/расход, сумма €, раздел (Хозяйство / Дом / Ферма / Личное), категория (корм, ветеринар, коммуналка,
ремонт, продукты, продажа молока/яиц и т.д. — свои можно добавлять), заметка.
- Итоги за месяц: доходы, расходы, разница; по разделам и категориям; переключение месяцев.
- Экспорт в CSV (Excel открывает) — через уже существующую `saveFile()`.
- Покупка корма на складе может по кнопке попадать сюда расходом.

## 3. Напоминания и телефон
- Свои уведомления: при открытом приложении раз в минуту проверять сроки и показывать уведомление через
  `navigator.serviceWorker.ready.then(r => r.showNotification(...))`. Разрешение спрашивать кнопкой, а не сразу при входе.
- Надёжные напоминания при закрытом приложении — через календарь телефона:
  у каждого дела кнопки «В Google Календарь» (ссылка `https://calendar.google.com/calendar/render?action=TEMPLATE&text=…&dates=…&details=…`)
  и «Скачать .ics» (с `VALARM` под выбранное напоминание и `RRULE` для повтора). Кнопка «Все дела в календарь» — один .ics.
- Утреннее письмо (по желанию, в настройках): в существующую `weekly-report` или отдельную функцию —
  ежедневно в 06:30 по Риге список дел на сегодня и просроченных (pg_cron, как `002_weekly_cron.sql`, тот же Resend).
- «Поделиться» в приложение: в `vite.config.js` → `manifest.share_target`
  (`{ action: './', method: 'GET', params: { title: 'title', text: 'text', url: 'url' } }`).
  При открытии с этими параметрами — сразу форма нового дела с подставленным текстом. Так письмо из Gmail
  или сообщение из WhatsApp на телефоне превращается в дело через «Поделиться» → «Подворье».

## 4. Не делать на этом этапе
- Прямое подключение к Gmail и OAuth Google: это проверка доступа Google и повторный вход примерно раз в неделю.
  Позже, отдельным этапом, если понадобится двусторонняя синхронизация с Google Календарём.

## Правила
- Интерфейс на русском, крупные кнопки, удобно одной рукой; стиль — как у остального приложения.
- Ключи только в `.env` и секретах Supabase, не в коде.
- Помощнику Claude (ask-farm) добавить в контекст дела на сегодня/неделю, чтобы он мог подсказать, что запланировать.
- В конце: обновить README (разделы, где что лежит), `npm run build` без ошибок, затем `npm run deploy`.

## 5. «Цены рядом» — сводка цен по региону (Krāslava, Daugavpils, Rēzekne, Preiļi)
Что собирать: зерно и корма (пшеница, ячмень, овёс, кукуруза, комбикорм для кур и коз, сено/сенаж — €/кг или €/т),
дрова (берёза/смешанные, €/насыпной м³, с доставкой или без), топливо (95, дизель — по заправкам в этих городах),
скидки и акции (где, до какого числа). У каждой цены — где (магазин/объявление, город), когда видели, ссылка на источник.

Как сделать:
- Новая Edge Function `prices` (ключ Claude только на сервере, как в `ask-farm`): Claude API с серверным инструментом
  веб-поиска (web search tool; точный тип и параметры — по docs.claude.com, указать `user_location` Латвия,
  `max_uses` ~15). Ответ — строго JSON по схеме: `{ category, item, price, unit, place, town, seen_on, url, note }[]`
  + короткий вывод «где сейчас выгоднее».
- Запуск по расписанию: pg_cron 2 раза в неделю (пн и чт, ~06:00 по Риге), как `002_weekly_cron.sql`.
  Плюс кнопка «Обновить сейчас» в приложении — не чаще 1 раза в день на хозяйство (счётчик на сервере).
- Хранение: таблица `price_digests (id, farm_id, created_at, items jsonb, summary text)`, RLS — читают участники хозяйства,
  пишет только сервер. Только для хозяйств с `ai_enabled`.
- В приложении: блок «Цены рядом» (на вкладке «Запасы» или отдельный экран): когда есть интернет — подтягивает последнюю
  сводку и кладёт в телефон; без интернета — показывает сохранённую с датой «обновлено …».
  Сравнение со своими ценами из `S.feeds[...].price`: «у вас овёс 0,32 €/кг, в Резекне видели 0,26 €/кг — объявление от 5.11».
  Кнопки: «Открыть источник», «В дела» («Позвонить и купить овёс в Резекне»).
- Честно показывать: цены из объявлений и сайтов — ориентир, перед поездкой звонить. Без даты и ссылки цену не показывать.
- Стоимость: веб-поиск в Claude API — около 10 $ за 1000 поисков плюс токены; 2 сводки в неделю — копейки в месяц.

## 6. Счета к оплате (коммуналка, кредиты, связь, страховки, налоги и т.п.)
Счёт: кому (получатель: Latvenergo, Daugavpils ūdens, банк, телеком…), за что, раздел (Дом / Хозяйство / Ферма / Личное),
сумма (постоянная или «каждый раз разная»), срок оплаты, повтор (каждый месяц / квартал / год / разово),
реквизиты получателя для перевода (название, IBAN получателя, назначение платежа / номер договора или клиента), заметка.
- Экран «К оплате»: просрочено (красным) → на этой неделе → в этом месяце; сверху итог «К оплате в ноябре: … €».
- Кнопка «Оплачено» — отмечает, сама создаёт расход в «Учёте» (сумма, раздел, категория) и ставит следующий счёт по повтору.
  Для «разной» суммы — спросить сумму при отметке.
- Кнопка «Скопировать реквизиты» (получатель, IBAN, назначение, сумма) — чтобы вставить в интернет-банк. Сами платежи приложение не делает.
- Добавить счёт по фото: сфотографировать счёт → помощник (уже есть распознавание фото) достаёт получателя, сумму,
  срок, IBAN и назначение → Настя проверяет и сохраняет.
- Напоминания — как у дел: за 3 дня и в день срока (уведомление, .ics / Google Календарь, строка в утреннем письме).
- В помощника: «сколько мы платим за свет в среднем за месяц», «что выросло» — из истории оплаченных счетов.
- Не хранить: номера и PIN карт, пароли и коды интернет-банка. Свой счёт — только последние 4 цифры, если нужно.

## 7. Машина: бензин, расход, техосмотр
Машина (можно несколько): название, номер, топливо (95 / дизель / газ), дата следующего техосмотра (tehniskā apskate, CSDD),
дата окончания OCTA (страховка), КАСКО — если есть, плановое ТО/масло (каждые N км или N месяцев).
Заправка: дата, литры, сумма €, цена за литр (считается сама из двух других, любые два поля из трёх), пробег по одометру,
«полный бак» (да/нет), заправка (Circle K, Neste, Viada, Virši… — список запоминается), заметка.
- Расход л/100 км — считать между двумя заправками «до полного бака» (литры всех заправок между ними / пройденные км × 100);
  если пробег меньше прошлого — предупредить об ошибке ввода.
- Итоги: расход сейчас и средний, €/км, € за месяц и за год, график расхода и трат по месяцам, самая дешёвая заправка
  по своей истории (и из «Цен рядом», п. 5).
- Каждая заправка сама попадает расходом в «Учёт» (раздел Личное/Ферма — выбор, категория «Топливо»).
- Быстрый ввод одной формой с крупными полями; по желанию — фото чека/колонки → помощник достаёт литры, сумму, цену.
- Напоминания (как у дел и счетов): техосмотр — за 30 дней, за 7 дней и в день; OCTA — за 14 дней и в день;
  ТО/масло — по пробегу (последний одометр) или по дате, что раньше. После прохождения — ввести новую дату следующего.
- В помощника: «сколько мы тратим на бензин в месяц», «вырос ли расход».

## 8. Покупки: списки продуктов, корзина деду, где дешевле, маршрут по магазинам
- Списки: «Домой», «Деду» (и свои — можно добавлять). Товар: название, сколько, единица, заметка («Rimi, молоко 2,5%»).
  Добавлять быстро: строкой, голосом (клавиатура телефона), из истории — частые товары сверху.
- «Собрать корзину деду из прошлых покупок»: показать, что раньше брали деду, отметить галочками → готовый список.
- Режим «В магазине»: крупные галочки, работает без интернета; при отметке «куплено» — поле «цена на полке»
  (по желанию), цена запоминается за этот магазин и дату. Купленное по кнопке «Итог» → расход в «Учёт».
- Магазины: Maxima, Lidl, Rimi, Mego, Elvi, top! и свои (названия «Соло» и «Бета» уточнить у Насти). У каждого — адрес
  выбранного филиала (Даугавпилс и рядом), можно несколько.
- Цены: (1) свои — из «цены на полке», самые точные; (2) раз в месяц и перед большими покупками — сводка акций и цен
  через ту же функцию поиска, что в п. 5 (каталоги акций сетей, с датами «действует до»). Нет данных о цене — так и писать
  и просить Настю внести цену в магазине; не выдумывать.
- «Где что купить»: по списку и ценам посчитать варианты — всё в одном магазине / разделить на 2–3 магазина.
  Разделять, только если экономия больше затрат на лишнюю остановку (км × €/км из раздела «Машина», п. 7, + время;
  порог по умолчанию 3 €, меняется в настройках). Показать: «Lidl: молоко, яйца, сыр — 14,20 €; затем Maxima: …;
  экономия 4,80 € против одного магазина». Начальная точка — дом (адрес в настройках), можно «я сейчас в городе».
- Маршрут: кнопка «Открыть маршрут» — ссылка Google Maps с остановками в выбранном порядке
  (`https://www.google.com/maps/dir/?api=1&origin=…&destination=…&waypoints=…`), порядок — самый короткий объезд.

## 9. «Сделай мне удобнее» — улучшения приложения через помощника
- В помощнике (ask-farm) режим «Предложить улучшение»: Настя пишет, что неудобно или чего не хватает.
  Помощник уточняет, честно обсуждает — надо или не надо, что лучше, есть ли это уже в приложении (тогда показывает где).
- Что можно сразу без программиста — помощник меняет сам после её «да»: настройки из белого списка
  (порядок и видимость вкладок, разделы и категории учёта, магазины, напоминания по умолчанию, порог экономии, адрес дома).
  Только через проверенный набор полей `S.settings`, никакого произвольного кода.
- Что требует изменения программы — сохраняется заявкой: таблица `feature_requests (id, farm_id, created_by, text,
  summary, status new/accepted/done/declined, created_at)`, RLS как у хозяйства. Даинис видит список заявок и кнопку
  «Скопировать как задание для Claude Code». Настя видит статус своих заявок.

## Порядок работы (рекомендация)
1) Дела + напоминания + календарь → 2) Счета → 3) Учёт → 4) Машина → 5) Покупки (без цен из интернета) →
6) «Сделай мне удобнее» → 7) Цены рядом и акции магазинов (нужны серверная функция, расписание и секреты).
После каждого шага — сборка без ошибок и короткий список, что проверить на телефоне.
